Sobre o Repositório

Este repositório é dedicado ao estudo e desenvolvimento de projetos utilizando **HTML**, **CSS** e **JavaScript**.

Aqui você encontrará exemplos práticos, exercícios e pequenas aplicações focadas em:
- Estruturação de páginas web com **HTML**
- Estilização e layouts responsivos com **CSS**
- Interatividade e lógica de programação com **JavaScript**

O objetivo é praticar e evoluir continuamente no desenvolvimento Front-end, reunindo códigos organizados e fáceis de entender.
